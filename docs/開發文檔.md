# 太平國小 3D 防災校園地圖｜開發文檔

> 版本：v0.8（2026-10-25）
> 狀態：P0～P4 完成；第三輪修改（外觀依實景重做）完成，見第 10 節「第三輪修改紀錄」
> 前身：`新竹縣關西鎮太平國民小學 3D 數位校園地圖.html`（Gemini 版，僅沿用資料內容，不沿用程式）

## 1. 專案目標

做一個**手機就能開**的 3D 校園地圖，讓使用者操作小人物在校園裡自由走動、認識環境，並能一鍵看到**各班的地震疏散路線**。

| 項目 | 內容 |
|---|---|
| 主要使用者 | 學生、家長、校外人士（來訪、辦活動、志工） |
| 主要裝置 | **手機優先**，其次平板、電腦 |
| 入口 | 學校網站按鈕連結 + 校內張貼 QR Code |
| 是否登入 | 不需要，所有人都能自由探索 |
| 畫面風格 | 簡化方塊造型 + 實景照片貼圖（司令台壁畫、TPES 圍牆、正門等） |

### 三大核心功能
1. **自由探索**：搖桿／鍵盤操作人物在校園內走動，可走樓梯上 2F。
2. **找地點**：搜尋或點選地點，人物自動沿路線走過去，並顯示該地點的介紹卡。
3. **疏散演練**：選一個班級，人物從教室沿正確樓梯走到操場中央集合點。

## 5. 座標與比例規則（解決「一調整就跑掉」）

Gemini 版的問題：走廊、樓梯、戶外設施有約 90 處座標直接寫死在程式裡，單位也不是公尺，改一處其他地方就對不上。

新版規則：
1. **單位一律公尺**，1 單位 = 1 公尺。
2. **原點 (0, 0) = 操場中央**（也就是疏散集合點）。
3. **方向以平面圖為準**：x 往平面圖右方、z 往平面圖下方（竹18縣道那側）、y 往上。
   真實的北方另外用指北針顯示（平面圖上的北是斜的）。
4. **比例校正**：以跑道一圈 125 m 推算跑道尺寸，再用正上方空拍照量出其他建物位置。
5. **所有物件的位置、大小都寫在資料檔**（`campus.json`），程式只負責「照資料畫出來」，不能在程式裡另外寫座標。
6. **編輯模式**：網址加 `?edit=1` 會出現編輯工具，可直接在畫面上拖動物件、調大小，再匯出新的 `campus.json`。只有管理者會用到，一般使用者看不到。

### 參考尺寸（初估，P0 階段會校正）
| 項目 | 數值 |
|---|---|
| 跑道一圈 | 125 m |
| 樓層高 | 約 3.6 m |
| 走廊寬 | 約 2.5～3 m（依影片估計） |
| 走廊抬高 | 約 0.3 m（兩階） |
| 人物身高 | 約 1.3 m（國小生） |

## 6. 資料結構

一個 `campus.json` 管全部內容，之後要改教室名稱、說明、防災設備，只要改這個檔案。
下方是規劃時的示意，**實際格式以 `app/src/data/campus.json` 為準**（P0 實作時，建物改為每棟一筆，走廊由建物的 `corridor` 欄位自動產生）。

```jsonc
{
  "meta": { "schoolName": "新竹縣關西鎮太平國民小學", "version": "115.07" },

  // 建物：外殼
  "buildings": [
    { "id": "bldg-main", "name": "教學大樓", "floors": 2, "floorHeight": 3.6,
      "wings": [ { "id": "wing-north", "x": 0, "z": 0, "w": 36, "d": 9, "corridorSide": "south" } ] }
  ],

  // 空間：教室、辦公室
  "rooms": [
    { "id": "room-2f-5a", "name": "五甲教室", "floor": 2, "wing": "wing-south",
      "category": "class", "x": 0, "z": 0, "w": 12, "d": 8.5,
      "door": { "x": 0, "z": 0 },
      "evacuation": { "stair": "stair-east", "assembly": "assembly-center" },
      "description": "…", "safetyItems": ["滅火器"] }
  ],

  // 戶外：司令台、樹屋、遊戲區、桌球桌 ×2 …
  "outdoor": [ { "id": "zone-stage", "name": "司令台", "shape": "box", "x": 0, "z": 0, "w": 0, "d": 0, "h": 0, "texture": "stage-mural.jpg" } ],

  // 樓梯
  "stairs": [ { "id": "stair-east", "name": "東側樓梯", "x": 0, "z": 0, "w": 3, "d": 6, "direction": "north" } ],

  // 防災點：AED、滅火器、消防栓、急救站、指揮中心、物資、集合點 …
  "safety": [ { "id": "assembly-center", "type": "assembly", "name": "操場中央集合點", "x": 0, "z": 0 } ],

  // 可行走路網：自動導航用（路口節點 + 連線）
  "navGraph": { "nodes": [], "edges": [] },

  // 通報電話（沿用 Gemini 版）
  "contacts": [ { "group": "災害通報單位", "name": "教育部校安中心", "tel": "02-33437855" } ]
}
```

Gemini 版已整理好的教室說明、防災設備、通報電話會搬過來，座標全部重新校正。

## 7. 功能規格

### 7.1 視角
| 模式 | 說明 |
|---|---|
| 第三人稱（預設） | 鏡頭跟在人物後方，可旋轉 |
| 鳥瞰 | 斜上方看全校，可縮放、拖曳 |
| 平面 | 正上方往下看，像平面圖，方便對照 |

### 7.2 人物
- 方塊造型小人，男孩／女孩兩款（制服配色可再定）。
- 簡單走路擺手動畫，用程式畫，不需外部模型、沒有授權問題。
- 不能穿牆、不能走進水池或花圃；樓梯可以上下。

### 7.3 操作
| 裝置 | 移動 | 轉視角 |
|---|---|---|
| 手機／平板 | 左下虛擬搖桿 | 右半邊螢幕拖曳 |
| 電腦 | WASD／方向鍵 | 滑鼠拖曳、滾輪縮放 |
| 共通 | 點地面 → 人物走過去；點建物／地點 → 開資訊卡 | |

### 7.4 找地點（自動導航）
- 上方搜尋框，可搜教室、戶外地點、防災設備。
- 選定後，地上出現黃色導引線，人物自動走過去（可暫停、加速）。
- 抵達後顯示資訊卡：名稱、照片、說明、附近防災設備。
- 每個地點都有分享連結（例：`…/#room-2f-5a`），家長點開就直接看到那間教室。

### 7.5 疏散演練（本專案特色）
1. 點「疏散演練」→ 選班級（一甲～六甲、藝動、資訊…）。
2. 人物出現在教室門口，地上顯示路線：
   - 2F 五甲、藝動 → 東側樓梯 → 操場中央
   - 2F 其他教室 → 西側樓梯 → 操場中央
   - 1F 教室 → 走廊 → 操場中央
3. 人物自動走完全程，畫面顯示距離和預估步行時間。
4. 到達後顯示「抵達集合點」與地震避難原則（先避難再疏散）。

### 7.6 防災圖層
- 開關按鈕，顯示 AED、滅火器、消防栓、急救站、指揮中心、物資儲備點、救援器材、通訊設備、災時家長接送區。
- 圖示與平面圖圖例一致。
- 「通報電話」面板：手機上可直接點擊撥號。

### 7.7 樓層
- 第一階段：按鈕切換 1F／2F（看 2F 時會隱藏屋頂）。
- 第二階段：人物走樓梯上 2F 時自動切換。

│ [≡] 太平國小 3D 校園  [?] │ ← 頂欄：選單、說明
│ [🔍 搜尋地點……………………] │
│                         │

- 按鈕至少 44×44 px，大拇指點得到。

- 第一次開啟時顯示三步驟教學（搖桿移動、拖曳轉頭、搜尋地點），可跳過。
- 手機直式、橫式都要能用；電腦版改為左側清單 + 右側資訊卡。

## 9. 技術架構與發布

### 9.1 技術選擇
| 項目 | 選擇 | 原因 |
|---|---|---|
| 3D | Three.js 0.169（放在專案內 `app/vendor/three/`） | 免費、資料多；放在專案內不怕外部網站掛掉 |
| 開發工具 | **免安裝**：瀏覽器原生模組（import map） | 電腦沒有 Node.js，也不需要；畫面效果和用打包工具相同 |
| 本機預覽 | `tools/serve.py`（Mac 內建 Python） | 雙擊 `啟動預覽.command` 即可，編輯模式可直接存檔 |
| 介面 | 原生 HTML/CSS | 不加框架，維持簡單 |
| 導航 | 路網節點 + 最短路徑 | 校園小，不需要複雜的導航網格 |

### 9.2 資料夾結構
```
3D地圖（太平國小）/
├─ README.md                 ← 怎麼開啟、怎麼編輯
├─ 啟動預覽.command          ← 雙擊啟動本機預覽
├─ docs/開發文檔.md          ← 本文件
├─ 素材/                     ← 原始照片、影片（不上傳）
├─ legacy/                   ← Gemini 版保存備查
├─ tools/serve.py            ← 本機預覽伺服器（含儲存）
├─ tools/textures/           ← 產生校徽、太平T 圖案、校門與衛生室貼圖（swift 腳本）
└─ app/                      ← 網站本體（整個發布）
   ├─ index.html、styles.css
   ├─ vendor/three/          ← Three.js
   ├─ public/ref/            ← 對位用空拍
   └─ src/
      ├─ main.js             ← 相機、操作、樓層切換
      ├─ data/campus.json    ← 全部校園資料
      ├─ scene/              ← 地面、建物（build）、戶外設施（outdoor）、程式畫的貼圖（textures）
      ├─ ui/                 ← 介面、資訊卡
      ├─ editor/             ← ?edit=1 編輯模式
      ├─ player/             ← （P2）人物、操作、碰撞
      └─ nav/                ← （P3）自動導航、疏散路線
```

### 9.3 發布：建議 GitHub Pages
| 方案 | 費用 | 管理 | 備註 |
|---|---|---|---|
| **GitHub Pages（建議）** | 免費 | 一個 GitHub 帳號管全部 | 適合學校非營利使用，沒有商用條款疑慮 |
| Vercel | 免費（Hobby） | 要多一個平台帳號 | 免費方案限個人非商業用途 |
| Netlify | 免費 | 要多一個平台帳號 | 功能類似 Vercel |

**流程**：程式放在 GitHub，每次更新後自動發布，網址會是 `https://帳號.github.io/tpes-3d-map/`。

**掛到學校網站**：
- 主要做法：在學校網站放「3D 校園地圖」**按鈕連結**，另開新頁。手機用全螢幕操作最順。
- 校內張貼 **QR Code**（川堂、校門口、家長日資料），掃了就能開。
- 不建議用 iframe 嵌入學校網頁：手機畫面太擠，搖桿也容易和網頁捲動互相干擾。

> 注意：GitHub Pages 免費版的程式庫是公開的。地圖本來就是公開資訊沒問題，但**不要放學生姓名或學生照片**。

### 9.4 效能目標（手機）
- 首次載入 < 5 MB，4G 網路約 5 秒內可操作。
- 一般手機維持 30 fps 以上。
- 做法：方塊造型、貼圖壓縮、陰影簡化、限制解析度倍率。
