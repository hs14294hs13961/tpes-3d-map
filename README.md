# 太平國小 3D 校園地圖

完整規劃見 [docs/開發文檔.md](docs/開發文檔.md)。

## 怎麼打開來看

不需要安裝任何東西（只用 Mac 內建的 Python）。

1. 雙擊 `啟動預覽.command`（第一次若被擋，按右鍵 →「打開」）
2. 瀏覽器會自動開啟編輯模式：`http://localhost:5173/?edit=1`
3. 一般瀏覽畫面：`http://localhost:5173/`
4. 用完關掉那個終端機視窗即可

## 編輯模式怎麼用

- **最簡單的方式**：在面板的「找物件」輸入名稱（例如「雞舍」），從清單點選
- 用「微調位置」的方向鍵移動（每次 0.2／1／5 公尺可選），鍵盤方向鍵也可以
- 也可以點畫面上的物件或標籤選取，再拖曳紅／藍箭頭；按 R 切換成旋轉、T 切回移動
- 也可以直接改數字（單位：公尺）
- 方向說明：↑ 是平面圖的上方（遊戲區那側），↓ 是竹18縣道那側
- 「調整底圖」可以移動、縮放空拍照；「底圖透明度」拉桿方便對照
- 按「儲存」直接寫回 `app/src/data/campus.json`，舊版自動備份到 `tools/backups/`
- 標籤後面有紅色「?」的，是位置還沒確認的物件

## 資料夾

| 路徑 | 內容 |
|---|---|
| `app/` | 網站本體（之後整個資料夾發布到 GitHub Pages） |
| `app/src/data/campus.json` | **所有校園資料**：位置、尺寸、名稱、說明、防災點、電話 |
| `app/src/scene/` | 3D 場景（依資料畫出建物、跑道、戶外設施） |
| `app/src/editor/` | 編輯模式 |
| `app/public/ref/aerial-top.jpg` | 對位用的正上方空拍（已轉成平面圖方向） |
| `app/vendor/three/` | Three.js 0.169（MIT 授權） |
| `tools/serve.py` | 本機預覽伺服器（含儲存功能） |
| `素材/` | 原始照片與影片（不上傳） |
| `legacy/` | Gemini 舊版，僅供參考 |

## 發布到網路

詳細步驟見 [docs/開發文檔.md](docs/開發文檔.md) 的「發布步驟」。重點：

- 只會上傳 `app/`、程式與文件；`素材/`、舊版、空拍照、編輯備份都在 `.gitignore` 裡，不會上傳
- 推送到 GitHub 的 `main` 之後，`.github/workflows/pages.yml` 會自動發布網站
- 海報：網站上線後打開 `網址/poster.html` 列印
